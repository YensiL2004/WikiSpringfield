## 📘 Descripción

Wiki Springfield es una página web estática dedicada a los personajes de la serie animada **Los Simpson**. Está construida como un trabajo de programación para internet, con diseño responsive y navegación sencilla entre las páginas principales e internas.

## 🚀 Tecnologías utilizadas

- 🌐 `HTML5`
- 🎨 `CSS3`
- 📦 `Bootstrap 5`
- 🖼️ Imágenes locales en `img/`
- 🗂️ Estructura de archivos simple con `index.html`, `css/`, `pages/` e `img/`

## 🧩 Estructura del proyecto

```text
WikiSpringfield/
├─ css/
│  ├─ bootstrap.min.css
│  └─ style.css
├─ img/
│  ├─ simpson.webp
│  ├─ homero.png
│  └─ ...
├─ pages/
│  ├─ familasismpson.html
│  └─ homero.html
└─ index.html
```

## 🛠️ Instalación y uso

1. Clona el repositorio o descarga los archivos.
2. Abre `index.html` en tu navegador preferido.
3. Navega entre las secciones disponibles desde la barra de menú.

> No requiere servidor ni instalación adicional; el sitio funciona como una página estática.
